⚙️ Ρυθμίσεις

Το token αποθηκεύεται μόνο στον browser σου (localStorage).
Δεν μπαίνει πουθενά στον κώδικα — δεν το βλέπει κανείς άλλος.
Πώς να φτιάξεις token:
GitHub → avatar → Settings → Developer settings
→ Personal access tokens → Tokens (classic)
→ Generate new token → επίλεξε repo → Generate
Αντέγραψε το token και επικόλλησέ το εδώ.
