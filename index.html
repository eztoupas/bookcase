Καλώς ήρθες στη Βιβλιοθήκη!

Για να λειτουργήσει η σελίδα, άνοιξε το αρχείο config.js και βάλε το GitHub username και το repository name σου.

1 Άνοιξε το config.js
2 Άλλαξε YOUR_GITHUB_USERNAME με το username σου
3 Άλλαξε YOUR_REPOSITORY_NAME με το όνομα του repo
4 Ανέβασε τα αρχεία στο GitHub και ενεργοποίησε το GitHub Pages
